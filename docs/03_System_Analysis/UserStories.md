# User Stories — PlantHub Bangladesh

**Document Version:** 1.0
**Status:** Draft — Development Phase
**Last Updated:** 2026-08-06

---

Format: *As a [role], I want to [action], so that [benefit].*
Each story references its Functional Requirement ID for traceability.

## Customer

- As a Customer, I want to filter plants by sunlight and water requirement, so that I can find plants suited to my home. *(FR-MKT-03)*
- As a Customer, I want to save plants to a wishlist, so that I can buy them later. *(FR-MKT-05)*
- As a Customer, I want to follow a nursery, so that I get notified about their new arrivals. *(FR-MKT-06, FR-NOTIF-02)*
- As a Customer, I want to track my order status in real time, so that I know when it will arrive. *(FR-NUR-06, FR-NOTIF-01)*
- As a Customer, I want to book a chat consultation with a plant expert, so that I can get help caring for a sick plant. *(FR-CON-01–04)*
- As a Customer, I want to upload growth photos of my plant over time, so that I can track its progress and share it with others. *(FR-REV-02)*
- As a Customer, I want to read verified plant care guides, so that I can learn how to take care of what I buy. *(FR-KH-01, FR-KH-02)*

## Nursery Owner

- As a Nursery Owner, I want to get a low-stock alert, so that I can restock before I run out. *(FR-NUR-03)*
- As a Nursery Owner, I want to set different prices for retail vs. wholesale buyers, so that I can serve different customer segments. *(FR-NUR-05)*
- As a Nursery Owner, I want to see which products sell best, so that I can plan inventory and marketing. *(FR-NUR-08)*
- As a Nursery Owner, I want an auto-generated invoice for each order, so that I don't have to create one manually. *(FR-NUR-09)*
- As a Nursery Owner, I want to apply for verification, so that customers trust my shop more. *(FR-VER-01, FR-VER-02)*
- As a Nursery Owner, I want to be notified immediately when a new order comes in, so that I can start fulfillment quickly. *(FR-NOTIF-03)*

## Plant Expert

- As a Plant Expert, I want to set my available consultation time slots, so that customers can book around my schedule. *(FR-CON-02)*
- As a Plant Expert, I want to write blog posts with product/consultation links, so that I can earn commission when readers act on my advice. *(FR-KH-01, FR-KH-03)*
- As a Plant Expert, I want to see my earnings dashboard, so that I can track my income from the platform.

## Platform Administrator

- As an Administrator, I want to review nursery verification requests, so that only legitimate businesses get verified. *(FR-VER-01–03, FR-ADM-02)*
- As an Administrator, I want to moderate submitted blogs before they go live, so that content quality stays high. *(FR-ADM-03)*
- As an Administrator, I want to configure commission rates, so that the platform's revenue model stays flexible. *(FR-ADM-04)*
- As an Administrator, I want platform-wide analytics, so that I can monitor overall health and growth. *(FR-ADM-05)*
